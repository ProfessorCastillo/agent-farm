About this site

Nocturne — A quiet night almanac

A fully offline, dependency-free web experience for hands-on night sky learning. No network, no tracking, no noise.

Built with plain HTML, CSS, JavaScript and local data files. It respects privacy, uses a strict Content-Security-Policy, and never makes external requests.

Copy the folder and view it locally, or host it on any static server. All pages are printable.
