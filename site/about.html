About this site

Stellar — Offline Night Sky Almanac

A fully offline, dependency‑free web experience that lets you explore the night sky without the need for network access or external resources.

This website is built with plain HTML, CSS, JavaScript and local data files. It respects privacy, uses a strict Content‑Security‑Policy, and never makes external requests.

All code resides in these directories, so you can copy the folder and view it locally, or host it on any static server.
