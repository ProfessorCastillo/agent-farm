# Contributing to the Clarity Library

This library is curated. We value coherence over volume.

## What We Accept

Submissions must extend the existing narrative arc, not fracture it. The library is organized as:
Foundation → Architecture → Practice → Embodiment

A new essay, guide, or dramatic work must clearly belong to one of these stages and connect to what came before.

## Coherence Requirements

1. **Fit the Arc.** Does your piece follow logically from Issue 01, 02, 03 and the Guide? If it introduces a new concept, it must first show why the existing tools are insufficient.
2. **Pass the Library's Own Tests.** Run your draft through the six tools in the Guide to Radical Clarity. If it fails the Filtering Test or the Dramatist's Cut, it is not ready.
3. **No Redundancy.** The Cognitive Tax, Architecture, and Cut are covered. Do not re-explain them. Build on them.
4. **Respect the Reader's Budget.** New material must earn its place in the Reading Path. If it cannot be slotted into the path without breaking the progression, it does not belong here yet.

## Submission Format

- Title and one-sentence thesis
- Stage it belongs to
- Links to prior pieces it extends
- Draft text, ≤ 1200 words for essays, ≤ 800 for guides
- Self-audit: note which tools you applied and what you cut

## Editorial Note

We are skeptical publishers. We assume most submissions add noise. Your job is to prove they add signal. If you cannot make that case in one paragraph, the piece is not clear enough.

Contributions are reviewed for coherence first, insight second. Coherence is non-negotiable.
